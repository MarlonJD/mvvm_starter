# Product Specs Index

Product specs describe what the app is meant to do from the user's point of
view. They are the first stop before changing user-facing behavior.

## Documents

- `mvvm-starter.md` - current product baseline for the starter app.

## Product Spec Rules

- Capture user-facing behavior, not implementation details.
- Include acceptance criteria for behavior changes.
- Link to execution plans when a spec is being implemented.
- Update specs when shipped behavior intentionally changes.
